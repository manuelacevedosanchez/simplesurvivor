# Music Assets

This folder should contain the following music files:

## Required Music Tracks (OGG format recommended):

- `menu_theme.ogg` - Main menu background music
- `game_theme.ogg` - In-game background music
- `game_over_theme.ogg` - Game over screen music (optional)

## Recommended specifications:
- Format: OGG Vorbis (smaller file size, good quality)
- Sample rate: 44100 Hz
- Bit rate: 128-192 kbps
- Channels: Stereo
- Loopable: Yes (for menu and game themes)

## Tips for game music:
- Keep file sizes reasonable (< 5MB per track)
- Ensure tracks loop seamlessly
- Consider having calm menu music and more intense game music
- Test on actual Android devices for performance
