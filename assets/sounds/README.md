# Sound Assets

This folder should contain the following sound effect files:

## Required Sound Effects (WAV format recommended):

- `shoot.wav` - Weapon firing sound
- `explosion.wav` - Enemy/asteroid explosion
- `powerup.wav` - Power-up collection
- `hit.wav` - Player taking damage
- `game_over.wav` - Game over jingle
- `button_click.wav` - UI button click
- `level_up.wav` - Level up / milestone reached
- `shop_purchase.wav` - Shop item purchased

## Recommended specifications:
- Format: WAV or OGG
- Sample rate: 44100 Hz
- Bit depth: 16-bit
- Channels: Mono (for sound effects)
- Duration: Short (< 2 seconds for most effects)

## Free sound resources:
- https://freesound.org/
